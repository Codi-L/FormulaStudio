# 调香手记（Formula Studio）

调香手记是一款为香水配方设计打造的本地桌面工具。它将配方管理、原料库、调配计算、试香评估与版本记录集中在一个简洁的工作区中，帮助你持续记录和完善每一次调香实验。

软件无需注册或登录即可使用。除非你主动开启坚果云同步或导出备份，否则所有调香数据都只保存在自己的电脑上。

## 主要功能

- 创建香水、香薰和香基配方。
- 按前调、中调和后调组织配方原料。
- 支持质量和体积两种计量方式，并记录香料浓度、溶剂种类与用量。
- 按目标用量等比例缩放配方，生成实际调配所需的称量数据。
- 建立可搜索的原料库，记录中英文名称、香调位置、原料类型、稀释状态、溶剂和浓度。
- 使用标签对配方和原料进行分类整理与快速筛选。
- 基于已有配方创建新版本，同时保留之前的实验记录。
- 记录静置时间、扩散力、香迹、留香时间、试香表现以及下一版本的调整方向。
- 将配方复制为 Markdown 文本，便于分享或整理文档。
- 通过 JSON 文件导入或导出完整数据备份。

## 开始使用

如果项目已经发布安装包，请从项目的 Releases 页面下载适合自己系统的版本：

- **Windows：**可选择安装版，或使用无需安装的便携版。
- **macOS：**打开 DMG 文件，将“调香手记”拖入“应用程序”文件夹。

启动软件后会直接进入工作区，无需注册账号。建议先在“原料库”中添加常用原料，再新建配方并将原料加入前调、中调或后调。随着实验推进，你可以调整配方、生成调配用量，或创建新版本继续记录。

## 数据与隐私

调香手记将数据保存在 `formula-studio-data.json` 文件中。默认位置为用户的“文档/Formula Studio”文件夹。你可以在“偏好设置”中选择其他保存位置；更换位置时，软件会将当前数据一并迁移。

软件偏好和加密凭据会单独保存在 Electron 的应用数据目录中。坚果云应用密码由操作系统的安全存储功能加密保存，不会写入导出的数据备份。

即使软件已经开启自动保存，也建议定期手动导出备份。侧栏中的“导出备份”和“导入备份”可以用于备份或迁移全部配方、原料、标签和设置。备份文件的详细结构见 [BACKUP_FILE_SPEC.md](BACKUP_FILE_SPEC.md)。

## 坚果云同步（可选）

调香手记支持通过坚果云 WebDAV 同步完整的数据备份。此功能默认关闭，可根据需要自行启用。

配置方法：

1. 在坚果云中打开“账户信息 → 安全选项 → 第三方应用管理”。
2. 生成一个应用密码。
3. 打开调香手记的“偏好设置”。
4. 填写坚果云账号、应用密码和云端备份路径。
5. 测试连接，保存设置，然后点击“立即同步”。

你可以启用定时自动同步、设置同步间隔，也可以选择在保存配方、原料、标签或设置后自动同步。如果云端数据比本地数据更新，软件会先提示你选择保留本地版本或坚果云版本，不会直接覆盖数据。

## 开发者信息

调香手记基于 Electron、React、TypeScript 和 Vite 构建。渲染进程采用分层结构，详细说明见 [ARCHITECTURE.md](ARCHITECTURE.md)。

### 开发环境

- Node.js 22 LTS 或更高版本
- npm
- Windows 10/11（用于生成 Windows 安装包）
- macOS（用于生成、签名和公证 macOS 安装包）

### 本地运行

```bash
npm install
npm run dev
```

### 验证生产构建

```bash
npm run build
```

### 打包桌面应用

```bash
# 生成 Windows 安装版和便携版
npm run dist:win

# 生成同时支持 Apple 芯片和 Intel 芯片的 macOS DMG
npm run dist:mac
```

打包结果会生成在 `release` 文件夹中。`npm run dist` 仍然是 Windows 打包命令的别名。
